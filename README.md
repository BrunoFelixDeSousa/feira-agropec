# Feira Agropec 2025

Bem-vindo ao repositório da plataforma da Feira Agropecuária de Paragominas!

Este projeto é uma aplicação web moderna para divulgação, organização e gestão da feira, com funcionalidades para visitantes e administradores.

## Documentação

- 👉 [**Guia do Usuário**](./USER_GUIDE.md): Como navegar, buscar informações, usar favoritos, notificações, mapa e acessar o painel administrativo.
- 👉 [**Documentação Técnica**](./TECHNICAL_DOC.md): Estrutura do projeto, arquitetura, APIs, comandos, detalhes de implementação e contribuição.

## Sobre o Projeto

A plataforma foi desenvolvida com Next.js, TypeScript, TailwindCSS e Prisma, visando performance, segurança e facilidade de uso tanto para o público quanto para a equipe organizadora.

- **Site público:** informações, programação, expositores, mapa interativo, favoritos e notificações.
- **Painel administrativo:** gerenciamento de eventos, expositores, notificações, configurações e estatísticas.

Consulte a documentação acima para detalhes de uso e desenvolvimento.
